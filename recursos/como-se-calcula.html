1 · Estadística descriptiva (Tema 1) #

Cómo se calcula cada medida descriptiva
QuéCómo se calculaEjemplo con los datos del tema
Frecuencia relativa hihi = fi / N; la suma de todas vale 1Consultas: f = 8 de N = 30 → 8/30 = 0,27
Acumuladas Fi y HiSe suman las anteriores: Fi = f1+…+fi; Hi = h1+…+hi8, 12, 21, 27, 30 (la última debe ser N = 30)
Tabla de doble entradaTotal de fila + total de columna; lo que falta = total − dato conocidoRespiratoria 1.432 − 583 = 849; no respiratoria 2.700 − 1.432 = 1.268; 1.268 − 314 = 954; columna 583 + 314 = 897 y 2.700 − 897 = 1.803
RangoR = xmáx − xmínPresión: 132,8 − 115,9 = 16,9. Colesterol: 215 − 183 = 32
Nº de intervalos (Sturges)k = 1 + 3,332 · log n, redondeadon = 20 → 5,3 → 5 · n = 25 → 5,65 → 5
AmplitudI = R / k, redondeada hacia arriba para que los intervalos cubran todos los datos16,9 / 5,3 = 3,18 → 4 (desde 115) · 32 / 5 = 6,4 → 7 (desde 183)
Marca de clasec = (a + b) / 2[183, 190) → 186,5; [211, 218) → 214,5
Sector del gráficoαi = 360° · hih = 0,25 → 90°
Mediax̄ = Σxi / nGlucosa: 2.489 / 25 = 99,56
MedianaOrdena los datos. Impar: valor central. Par: media de los dos centrales25 datos → posición 13 → 99
ModaValor con mayor frecuencia92 (se repite 5 veces)
CuartilesPosición N/4, N/2, 3N/4 sobre los datos ordenados. Si cae entre dos posiciones, se promedianQ1: 6,25 → posiciones 6 y 7 → (92 + 93)/2 = 92,5, que el curso redondea a 93 · Q2 = 99 · Q3: 18,75 → 105
Rango intercuartílicoIQR = Q3 − Q1105 − 93 = 12
VarianzaS² = Σ(xi − x̄)² / (n − 1)1.078,2 / 24 = 44,92 mg²/dL²
Desviación típicaS = √S²√44,92 = 6,70 mg/dL
Diagrama de cajasBigotes: mínimo y máximo. Caja: Q1 a Q3. Línea interior: medianaQ1 = 97, Q3 = 110, mín. 85, máx. 115

Orden de trabajo recomendado: ordenar → contar → acumular → calcular. Comprueba siempre que la última frecuencia acumulada sea N y que las hi sumen 1.

2 · Probabilidad (Tema 2) #

Cálculo de probabilidades
QuéCómo se calculaEjemplo con los datos del tema
Regla de LaplaceP(A) = casos favorables / casos posibles (siempre entre 0 y 1)Fármaco A: 760/800 = 0,95. Fármaco B: 340/500 = 0,68 → A es más efectivo
Suceso contrarioP(Ā) = 1 − P(A)1 − 0,95 = 0,05
Intersección, independientesP(A ∩ B) = P(A) · P(B)Par en dado y figura en baraja: 0,5 · 0,3 = 0,15 · Errores administrativos y clínicos: 0,30 · 0,20 = 0,06 = 6 %
Unión (Venn)P(A ∪ B) = P(A) + P(B) − P(A ∩ B)Se resta la intersección para no contarla dos veces

3 · Distribuciones continuas (Tema 2) #

Distribuciones continuas paso a paso
DistribuciónFórmulasEjemplo con los datos del tema
Uniforme (a, b)f(x) = 1 / (b − a) · P(x₁ ≤ X ≤ x₂) = longitud del tramo / longitud total · media = (a + b)/2Llegada entre 0 y 60 min: f = 1/60, media = 30 min
Exponencialλ = 1/μ · P(X ≤ x) = 1 − e−λx · P(X > x) = e−λxAmbulancia μ = 6, λ = 0,1667: P(X ≤ 3) = 1 − e−0,5 = 1 − 0,6065 = 39,35 % · P(X > 9) = e−1,5 = 22,31 %
Exponencial (urgencias)Mismo procedimiento con μ = 15 minλ = 1/15 = 0,0667 · P(X < 10) = 1 − e−0,6667 = 1 − 0,5134 = 48,66 %
Normal N(μ, σ)Simétrica en campana; media = mediana = modaPresión sistólica N(128, 25)
Tipificaciónz = (x − μ) / σ → N(0, 1); z indica cuántas σ está x de la media(115 − 121)/7 = −0,857 · 121 → 0 · 128 → 1,000
Regla empíricaμ ± 1σ ≈ 68 % · μ ± 2σ ≈ 95 % · μ ± 3σ ≈ 99,7 %Si z = −3, el dato está 3σ por debajo de la media
Puntuaciones z (estaturas)Media, σ poblacional (÷ N) y luego z de cada dato2.554/22 = 116,09 · σ = √(875,82/22) = 6,31 · 100 → (100 − 116)/6 = −2,667 con los redondeos del curso
Intervalo de confianza 95 %IC = x̄ ± z · σ/√n, con z = 1,96154 ± 1,96 · 5/√52 = 154 ± 1,36 → [152,64 ; 155,36] mmHg
t de StudentMuestras pequeñas; gl = n − 1 (dos muestras: (n₁−1) + (n₂−1))n = 8 glucosas → 7 grados de libertad
χ²gl = (filas − 1)(columnas − 1) en tablas de contingenciaTabla 2×2 → 1 grado de libertad

4 · Erratas y matices de las diapositivas #

Para no confundirte en el examen

• Uniforme: la diapositiva escribe f(x) = 1/(a − b); lo correcto es 1/(b − a), para que sea positiva.

• Regla empírica: aparece «98 %» y «99 %» para ±3σ; el valor exacto es 99,7 %.

• Ambulancia: una línea escribe 0,1663 en lugar de 0,1667; el resultado 39,35 % es el correcto.

• Varianza de la glucosa: la suma de cuadrados es 1.078,16 con datos exactos (1.078,27 con redondeos); en ambos casos S² = 44,92.

• Desviación: la varianza de una muestra divide entre n − 1; en las puntuaciones z de estaturas el curso divide entre N.
